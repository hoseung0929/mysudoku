## 2. 검증 환경과 방법

- Flutter 3.41.4 / Dart 3.11.1, macOS 호스트의 `flutter test`, `flutter analyze`.

## 4. 통계 지표의 실제 계산 의미

- 완료 기록(`clear_records`)은 퍼즐(난이도+번호)당 **최고 기록 1건**이다. 따라서 완료 수는 고유 퍼즐 수이고 반복 플레이는 중복 집계되지 않는다.
- "퍼즐 완료 현황"(구 클리어율/전체 완료율) = 완료한 고유 퍼즐 수 / 제공 퍼즐 수. 성공률이 아니다.
- "최고 기록 평균"(구 평균 시간) = 퍼즐별 최고 기록 시간의 평균. 전체 시도 평균이 아니다.
- "최고 기록의 평균 오답"·"무오답 완료 비율"은 모두 최고 기록 행 기준.
- "누적 완료 횟수"와 히트맵은 완료 이벤트(`clear_events`) 기준이라 **반복 완료를 포함**한다.
- 연속 일수는 완료 이벤트가 1건 이상 있는 날의 연속이다("시작만 한 날"은 포함하지 않음). 오늘의 도전 연속(`daily_challenge_completions`)과는 별개다.
- 계산 방식은 바꾸지 않았고 이름과 각주만 실제 계산에 맞췄다. 기록이 0건이면 평균 시간·평균 오답·무오답 비율은 "기록 없음"을 표시한다.

## 6. 기존 저장·완료 기록에 미치는 영향

- 저장 형식 변경 없음, 마이그레이션·일괄 삭제 없음. 구버전(문자열 보드, 노트 없는 JSON) 저장도 읽힘.
- 이전에 메모만 있던 저장 세션은 이제 진행 중으로 보인다(삭제되지 않음).
- 완료 기록·연속 기록은 삭제·재계산하지 않음. 오늘의 도전 타깃은 앞으로 그날 처음 확정한 값이 로컬에 고정된다(`daily_challenge_target_v1_<날짜>`).

## 7. 남은 실기기 확인과 미해결 사항

- 실기기·시뮬레이터에서의 시각 확인(작은 폰, 큰 글씨 최대 단계, 다크 모드, 긴 번역, 아이패드 가로) 전부. 지금까지는 테스트 뷰 크기 변경만 했다.
- VoiceOver 낭독 순서와 중복 낭독은 시맨틱 노드 수준까지만 확인했다.
- Apple Pencil 필기 인식은 실기기 없이 검증하지 않았다.
- 홈 화면의 오늘의 도전 흐름(날짜 변경·재시도·완료 후 갱신), 자정 직전 시작 → 이후 완료, 오프라인 첫 실행은 실기기 확인이 필요하다.
- 사전 실패 테스트 3건(마스터 레벨 관련 `MyPaceService` 2건, 챌린지 번호 선택 1건)은 이번 변경 이전 HEAD에서도 동일하게 실패함을 별도 worktree에서 확인했다. 이번 변경과 무관하다.
- 사용자가 열어두기만 한 진행 중 퍼즐도 타이머 저장 때문에 최근 순서가 바뀔 수 있다(의도된 "이어서 열기"로 간주).

- 홈 화면은 저장소 주입이 가능해져 `test/view/home/home_screen_test.dart`로 오늘의 도전 상태(미시작/진행 중/완료), 이어하기와 같은 문제일 때의 통합, 로딩·조회 실패·재시도, 연타 방지를 검증한다. 위 3절의 "F 홈 화면 자체" 항목은 이 테스트로 대부분 커버된다(날짜 변경 감지 분기는 여전히 위젯 테스트 없음).
