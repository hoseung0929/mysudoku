# 배포 내역

앱이 게시될 때 적용된 버전(`pubspec.yaml`)별로, 그 버전에 실제로 포함된 변경사항을 정리한 문서. git 태그가 없어 버전 경계는 `pubspec.yaml`의 버전 문자열이 바뀐 커밋을 기준으로 잡았고, **표시된 날짜는 커밋 날짜이지 App Store 실제 게시일이 아니다** — 정확한 게시일은 App Store Connect에서 확인 필요.

## 다음 배포 예정 (Sudoku159, 미출시 — 현재 `1.1.1+3` 작업 중)

아직 커밋되지 않았거나(작업 트리에만 있음) 커밋됐지만 아직 App Store에 제출되지 않은 변경사항. **버전이 실제로 게시되면 이 섹션 내용을 위 "1.1.1+3" 항목으로 옮기고 여기는 비운다.**

- **알림 정책 정리** (2026-09-24 갱신) — 한때 설정 토글을 되돌리고 알림을 하드코딩했으나, 이후 설정 화면에 알림 ON/OFF 토글을 다시 제공하는 쪽으로 확정. 하루 3회 → 저녁 8시 1회, 발송 조건은 "오늘 아무 퍼즐이나 1판 클리어하지 않았을 때". OFF면 시작 시 권한을 다시 요청하지 않고 기존 예약을 모두 취소. 알림 문구 5개 언어 (커밋 안 됨). 자세한 내용은 [project-status.md](project-status.md) "최근 완료".
- **UX 정리 (2026-09-20~21)** — 홈·퍼즐 선택·완료/게임오버 다이얼로그·기록 화면 재구성, 마스코트 보강, 홈 프로필 헤더 한 줄화, 자기소개 입력 제거(데이터는 보존), 인터랙션 효과 정리. [ui-ux-screen-review.md](ui-ux-screen-review.md) 참고 (커밋 안 됨).
- **다국어 확장 — 중국어(zh)·스페인어(es) 추가** — `arb/global/app_{zh,es}.arb` 신규 작성, 언어 선택 UI에 옵션 추가(일본 플레이버엔 미노출). 추가 과정에서 발견한 부수 버그도 같이 수정: 홈 인사말 문구·자기소개 글자수 제한·"n일 전" 표시·기록 화면 요일/월 라벨 등 arb 밖에 하드코딩돼 있던 언어 분기 4곳에 zh/es 대응 추가 (커밋 안 됨).
- **아이패드 가로 모드 지원** — [project-status.md](project-status.md)의 "진행 중" 항목 참고. 아이폰 전용 배포(`TARGETED_DEVICE_FAMILY=1`)라 이 자체가 배포를 막지는 않지만, 완료 전까지는 코드가 불완전한 상태로 다음 배포에 같이 나갈 수 있음 — 배포 전 반드시 완료 여부 재확인.
- **오늘의 도전 표시-시작 대상 일치** (2026-09-24) — 카드에 표시된 문제와 실제로 여는 문제를 일치시킴. 이전에 "미해결 이슈"로 적혀 있던 라벨-동작 불일치는 해결됨 (커밋 안 됨).
- **되돌리기·일시정지·홈 연속 일수 칩·힌트 풀이 설명(싱글 기법)** (2026-09-24) — 첫 완료의 "새 최고 기록" 문구 제거 포함. [project-status.md](project-status.md) "최근 완료" 참고 (커밋 안 됨).
- **출시 전 보완** (2026-09-24) — 힌트만 쓴 세션 저장, 알림 7일 예약, 첫 실행 권한 팝업 제거(첫 완료 후 안내), 개인정보 문서 정정, Android 예약 알림 리시버, iOS 번들 언어 es·zh-Hans(글로벌만). [project-status.md](project-status.md) 참고 (커밋 안 됨).
- **출시 전 추가 보완** (2026-09-26) — 알림 권한·예약 실패 시에도 완료 후 이동 보장·설정 OFF 복구, 알림 스위치 중복 입력 방지, iOS 번들 언어 플레이버 분리(일본 `Info-japan.plist`: en·ko·ja). (커밋 안 됨).
- **인터랙션 효과 1차** (2026-09-26) — 힌트 패널 등장·단계 전환, 되돌리기 결과 칸 강조, 기록 화면 요일·난이도 선택 전환에 짧은 모션을 추가. 동작 줄이기 전면 준수. [project-status.md](project-status.md) "최근 완료" 참고 (커밋 안 됨).
- **알려진 제약(인지만)**: 결과 텍스트 공유(`GameResultActions.shareResultText`)는 구현돼 있지만 어떤 화면에서도 호출되지 않음. `ChallengeScreen`은 어디에도 연결되지 않은 화면.
